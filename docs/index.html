Netlink

Neuereatec multi-connection downloader for Windows

Netlink downloads different parts of the same file through each internet connection you select, then assembles them on disk. It combines connections for its own downloads and requires no VPN or virtual network adapter.

Download for Windows (v1.0.0)

How it works

  • Each connection you select must be its own internet connection (e.g. two different ISPs, or Wi-Fi plus a phone hotspot).
  • Netlink downloads different parts of the same file through each connection in parallel, then assembles them on disk.
  • Each part is fetched over that connection’s own public IP; websites see several IPs, not one.
  • No VPN, virtual network adapter, server or VPS — everything runs locally on your PC.
  • It only speeds up downloads done inside the Netlink app, not your browser or other programs.

OpenWrt (planned)

No firmware rebuild is needed. Flash stock OpenWrt and install packages afterwards (apk from 25.12, opkg/.ipk on older releases). The plan is for the router to run the same downloader itself (each connection still with its own public IP; no bonded IP or tunnel): Netlink's engine as a headless service packaged with the OpenWrt SDK, with a procd init script and a web UI on the LAN. The router needs enough RAM and USB storage. Details are in the technical README.

Installing

The installer is not code-signed, so Windows SmartScreen may show “Windows protected your PC”. Click More info → Run anyway.
